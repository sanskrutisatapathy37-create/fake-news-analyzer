# fake-news-analyzer
An AI-powered fake news detection system that classifies news articles as Fake or Real using Python, NLP, TF-IDF, and Logistic Regression.
Developed a machine learning-based fake news detection system that classifies news articles as fake or real using Natural Language Processing (NLP). Implemented text preprocessing, TF-IDF vectorization, and Scikit-learn Logistic Regression to achieve high prediction accuracy on real-world datasets.
